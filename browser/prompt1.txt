# AiBrowser — “Eye Browser”
## Super-Slim • Super-Light • Absolutely Fast • AI-Native • Web3/DeFi • MCP Claw Agent

Build a production-ready desktop web browser named:

**AiBrowser**
**Codename / identity:** Eye Browser  
**Tagline:** Fast. Smart. Secure. Yours.

The product must feel like a completely new generation of browser: extremely lightweight, extremely fast, secure by default, AI-native, single-user, Chromium-compatible, Web3/DeFi capable, and equipped with a powerful free built-in download manager.

Do NOT make it look like a generic Chrome clone.

---

# 1. CORE PRODUCT PHILOSOPHY

AiBrowser is designed for one user on one machine.

Prioritize:

1. Startup speed
2. Page rendering speed
3. Low RAM usage
4. Low CPU usage while idle
5. Minimal disk footprint
6. Minimal background processes
7. Security
8. Privacy
9. AI assistance
10. Web3/DeFi usability
11. Shopping intelligence
12. Download performance
13. Automation
14. Stability

The browser must remain useful even when all AI, Web3, shopping and automation features are disabled.

The browser should never feel overloaded.

---

# 2. TECHNOLOGY FOUNDATION

Use:

- Chromium as the browser engine
- Latest stable security-supported Chromium baseline
- Native desktop implementation appropriate to the target OS
- Hardware acceleration
- Modern GPU compositing
- HTTP/2
- HTTP/3 / QUIC
- Brotli
- WebAssembly
- WebGPU where supported
- modern JavaScript/V8 optimizations

Do NOT fork unnecessary Chromium subsystems.

Remove or disable unnecessary:

- telemetry
- promotional services
- redundant background services
- unnecessary account synchronization
- unnecessary cloud dependencies
- unnecessary UI
- unnecessary preinstalled extensions
- consumer bloat

Do not compromise Chromium's security architecture merely to reduce binary size.

# 39. EYE VAULT — LOCAL-ONLY UNIVERSAL BROWSER VAULT

Build a core security subsystem called:

# Eye Vault

Eye Vault is AiBrowser's private, local-first identity and browser-data vault.

Its purpose is to allow the user to securely consolidate their digital browser information from supported browsers into one encrypted local vault.

The fundamental rule is:

> **The user's vault belongs only to the user. AiBrowser must never share it.**

No advertising system, analytics system, AI provider, MCP server, website, extension or third party receives vault contents by default.

# 41. VAULT ENCRYPTION

Use modern authenticated encryption.

Primary encryption:

**AES-256-GCM**

Use a strong password-based key derivation mechanism such as:

**Argon2id**

with parameters selected according to current security recommendations and calibrated during setup.

Architecture:

Master Password
↓
Argon2id
↓
Key Encryption Key
↓
Encrypted Vault Key
↓
AES-256-GCM encrypted vault

Use authenticated encryption for all sensitive vault objects.

Each encrypted object should have appropriate:

- nonce
- authentication tag
- version
- key identifier
- metadata required for migration

Never invent custom cryptography.

# EYE ID — 12-WORD LOCAL PASSPHRASE

AiBrowser uses a **12-word dictionary passphrase** as the primary and fundamental authentication secret for the local Eye identity.

The Eye identity is:

**local-first + passwordless + non-cloud-dependent**

During initial setup, AiBrowser generates a cryptographically secure sequence of exactly **12 words** from a sufficiently large approved dictionary.

Example format only:

`river ... ... ... ... ... ... ... ... ... ... ...`

The actual words MUST be generated using a cryptographically secure random source.

Do NOT generate the phrase from:

- predictable randomness
- timestamps
- usernames
- device information
- browser information
- AI-generated randomness
- user-selected predictable words

---

# THE 12 WORDS ARE THE MASTER SECRET

The 12-word passphrase is the fundamental secret from which the user's Eye Vault encryption keys are derived.

The browser must never know or retain the complete plaintext passphrase after the initial setup process except where technically unavoidable during controlled authentication.

Never store the 12 words in:

- browser database
- localStorage
- cookies
- logs
- analytics
- crash reports
- telemetry
- AI memory
- MCP memory
- plaintext configuration files

---

# USER MUST KEEP A COPY

The setup process MUST clearly tell the user:

> **This is your only master recovery secret.**
>
> Write down or securely store your 12 words.
>
> AiBrowser does not keep a copy.
>
> If you lose the 12 words and lose access to your authorized device/recovery mechanism, your encrypted Eye Vault may be permanently unrecoverable.

Provide a mandatory confirmation step.

### Secure your Eye ID

**Write it down and keep it somewhere safe.**

[ Show words ]

[ I have securely stored my 12 words ]
