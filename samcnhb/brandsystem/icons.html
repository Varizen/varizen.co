01 / Selection and license

Health Icons, outline family

Selected from the three sources listed in the supplied icon-system note. It offers the broadest relevant medical, education, people, place, object and wayfinding coverage.

One source

healthicons.org only. Do not mix with other approved alternatives. Original SVGs are stored locally for offline production.

Open license

Icons: CC0 1.0. Attribution is not required, but provenance is retained in the local registry and notices.

Not institutional marks

Icons support navigation and comprehension. They are not logos, accreditations, certifications or proof of service availability.

Terminology: “Outline” is the official family/variant name. Its paths may use fills, strokes, or both. Do not add filled-family icons or convert these to a different visual style. Website code is separately MIT-licensed; this package uses the CC0 icon artwork, not the website code.

03 / Scale and color

Legibility before decoration

24 / 32 / 64px

Use the official 24px variant for dense small UI after downloading it from the same family. The core sprite uses 48-unit source artwork. Minimum recommended standalone size: 24px digital / 8mm print after proof.

Color follows the model

Set CSS fill: currentColor or color. Model 01: Blue Professional #0B6FA4/#005A8C; Model 02: Green Wellness #16A34A with darker accessible action green; Model 03: Purple Innovation #7C3AED. Never mix model palettes or use low-contrast accents for essential navigation.

Reverse: white only

Maintain at least 3:1 contrast for meaningful graphics and 4.5:1 for accompanying normal-size text.

Source grid48×48 units; preserve aspect ratio and internal whitespace. Do not stretch, rotate or redraw individual paths.
SpacingAt least 8px between icon and label; at least 25% of icon width clear around standalone icons.
ButtonsRecommended target 44×44 CSS px; visible text label for primary actions; icon-only controls require an accessible name and tooltip.
SVG accessibilityDecorative: aria-hidden="true" and no extra title. Meaningful: accessible text label or visible adjacent text. Never rely on the icon alone for emergencies or status.
Color & dataNever recolor individual internal parts to imply clinical status. Do not use icon color alone to communicate urgency, eligibility, sex, risk or availability.
04 / Model-specific use

Same icons; different brand temperament

01 · Blue Professional

Primary/deep blue on white; structured institutional frames and cyan information accents. Pair hospital, training and approved-document icons with formal academic services.

02 · Green Wellness

Primary green with teal care accents; rounded journey modules. Pair hospital, training and community icons with patient/student actions.

03 · Purple Innovation

Purple/indigo with carefully tested pink/teal accents. Pair research, training and digital-service icons with verified learning and technology capabilities.

Do

Use official files, keep provenance, translate visible labels, test at actual size, use verified service names, and submit missing-icon requests to Health Icons.

Never

Mix icon families, use emoji as interface icons, imply a service that is unavailable, use a hospital cross as a logo, or let an icon substitute for emergency instructions.

05 / Source gallery

Original local SVG files

Production checklist

  • Choose icon from assets/icons/registry.json; use sprite or local standalone SVG.
  • Match model accent, verify contrast, and preserve the original source URL in the asset register.
  • Test English/Bangla labels, keyboard access, touch target and screen-reader name.
  • For new needs, select only another Health Icons outline asset and rerun python build_icons.py after adding its verified path.
  • Review official signage/emergency standards separately; brand icons never override legal wayfinding or safety signs.
