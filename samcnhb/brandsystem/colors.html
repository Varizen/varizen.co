03 / Shared semantic grammar

Colors have jobs, not just names

PrimaryMain actions, navigation, selected states and master-brand accents. Use accessible text/icon contrast.
Secondary / lightCards, hover backgrounds, secondary sections and soft emphasis. Use dark text, not pale text.
InfoInformation and tips; icon + heading + text. Never assume cyan/teal/indigo alone conveys status.
SuccessCompleted, approved and positive status. Shared semantic green: #15803D; on white 5.02:1. Use check + text.
WarningAttention/pending. Shared dark warning text: #92400E; background #FEF3C7; on background 7.06:1. Warm yellow/orange is a background/accent only.
ErrorValidation/critical status. Shared error: #B91C1C; on white 6.47:1. Use error icon + actionable message, never red alone.
Text primaryHeadings, body and important information. Model charcoal or #1A1A1A; avoid pure black on saturated color.
Text secondarySlate #475569 for descriptions and labels; on white 7.56:1. Gray #94A3B8 is a border/decorative value, not small secondary text.
Border / surfaceLight Gray #E5E7EB for dividers/inputs; model surface for cards. Essential boundaries need at least 3:1 or an alternative visual cue.

Non-negotiable: WCAG 2.2 AA target: 4.5:1 normal text, 3:1 large text and meaningful UI components. Compute actual foreground/background pairs; never infer accessibility from a palette’s name. Emergency/clinical signs follow applicable operational standards.

04 / Model assignment

One palette per model

01 · Blue Professional

Primary/deep blue for authority; cyan for information; warm orange for attention; reference logo red only where authorized. Clean institutional interfaces and formal documents.

Open model 01

02 · Green Wellness

Primary green for growth; teal for care; lime/yellow for optimistic highlights; coral for human warmth. Main buttons use a tested darker green for accessible white text.

Open model 02

03 · Purple Innovation

Purple/indigo for knowledge and digital experiences; pink for creative emphasis; teal/orange for balanced accents. Avoid technology claims without actual capability.

Export and production
