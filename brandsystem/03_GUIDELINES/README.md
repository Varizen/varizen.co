# Varizen Logo Brand Package

Prepared against the latest Varizen logo-use rules found in the Library.

## Recommended hierarchy
1. Primary Horizontal Color — default corporate/site header on light backgrounds; preferred for desktop navigation, footer, headers, cards and dashboards.
2. Primary Stacked Color — centered hero, mobile/compact compositions and splash/loading contexts.
3. Monochrome Horizontal Black — light-background print, documents, formal monochrome contexts and constrained media.
4. Monochrome Stacked Black — centered monochrome/compact use.
5. Reverse Horizontal White — dark navbar/footer, dark hero, image/video overlays.
6. Reverse Stacked White — dark centered hero, splash/loading/mobile contexts.

## Explicit usage rules
- White/reverse logos: dark backgrounds, hero sections, overlays, video/image backgrounds, dark navigation and footers.
- Original/colored logos: light backgrounds, clean sections, white cards, dashboards and pricing sections.
- Side-by-side/horizontal: navbar, footer, desktop headers, horizontal layouts and authentication pages.
- Up-and-down/stacked: mobile layouts, favicon adaptation, splash sections, centered hero branding and loading screens.
- Never stretch, squash, rotate, skew or distort the mark.
- Minimum clear space: at least 0.5× the logo height around the logo.
- Prefer transparent assets where available.
- Prefer SVG for production; PNG/WebP are fallbacks.
- Favicon/app icon should use the symbol-only V mark, not the full wordmark.
- Preserve the native proportions, geometry and digital-dispersion motif.

## Sizing reference
- Desktop navbar: 40–52 px logo height.
- Mobile navbar: 28–36 px logo height.
- Hero: typically 180–320 px width depending on composition.
- Footer: typically 24–40 px height.
- Favicon/app icon exports: 16, 32, 48, 180 and 512 px.

## Source policy
The `02_SOURCE_LIBRARY` folder retains all collected Library exports, including the duplicate variant, so no source asset is lost. The `01_RECOMMENDED_USE` folder is the curated operational set.
