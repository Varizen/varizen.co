## 1. Fundamental UX Axiom

> **UI IS A PROJECTION OF AUTHORIZATION. UI IS NOT A SECOND AUTHORIZATION SYSTEM.**

Every UI component, button, navigation link, and table column is rendered conditionally based on server-evaluated authorization. 
Tampering with browser client state or DOM elements cannot bypass backend API authorization checks.
