## 1. Master Brand Identity Standards

The SohaelTasneem Foundation (STFL) maintains an authoritative visual identity designed for quiet confidence, institutional trust, and human dignity.

### 1.1 Master Institutional Palette
- **Deep Navy (Brand Primary):** `#081F2D` — Institutional anchor, header text, dark surfaces.
- **Ocean Navy (Brand Secondary):** `#0B2B43` — Elevated dark cards, button hover states.
- **Vivid Sunset Orange (Brand Accent):** `#FF6B35` — Interactive focus, key CTAs, highlights.
- **Pure Canvas White:** `#FFFFFF` — Primary background, high-contrast text on navy.
- **Warm Off-White (Warm Surface):** `#FAFAF8` — Soft editorial card fills, ambient sections.
- **Fine Rule Gray (Border Ruling):** `#E7E7E2` — Subtle structural borders and separators.
- **Muted Charcoal (Body Text):** `#1A1A1A` / `#5A6B75` — Editorial readability.

### 1.2 Master Typography System
- **Bengali Headings & Headers:** `Hind Siliguri` (400, 500, 600, 700)
- **Bengali Body:** `Hind Siliguri` / `Noto Sans Bengali`
- **English Typography:** `Inter` / System UI font stack
- **Monospace & Metadata:** System Monospace (`ui-monospace`, `Menlo`, `Consolas`)

### 1.3 Iconography Rule
- **STRICTLY ICONOIR ONLY:** The web interface exclusively consumes `iconoir-react`.
- All icons render with `currentColor` and scalable dimensions (`14px` - `24px`).
- Prohibited: Lucide, Heroicons, FontAwesome, Material Icons, Feather.

## 3. Native Logo Preservation Mandate

1. **No Homogenization:** STFL does not replace native project logos with generic template icons.
2. **Controlled Adaptation:** Controlled black, white, and full-color variants are maintained in the Asset Register (`STFL_ECOSYSTEM_ASSET_REGISTER.json`).
3. **Mandatory Co-Branding Seal:** On standalone project pages, the native logo is prominently presented alongside the official governance trust seal:
   `"A project of SohaelTasneem Foundation"`
