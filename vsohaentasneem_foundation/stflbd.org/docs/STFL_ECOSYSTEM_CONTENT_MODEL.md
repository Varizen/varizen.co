## 1. The Content Truth Classification

To prevent hype, unsubstantiated commercial claims, or algorithmic hallucination, all public and internal statements regarding STFL projects are governed by a 7-stage Content Truth Classification:

```
┌────────────────────────────────────────────────────────────────────────┐
│                   STFL CONTENT TRUTH CLASSIFICATION                    │
├────────────────────┬───────────────────────────────────────────────────┤
│ STATE              │ DEFINITION & EVIDENCE STANDARD                    │
├────────────────────┼───────────────────────────────────────────────────┤
│ VERIFIED           │ Confirmed by physical deployment, active codebase, │
│                    │ statutory license, or executed legal agreement.   │
├────────────────────┼───────────────────────────────────────────────────┤
│ SOURCE-DERIVED     │ Extracted directly from authoritative repository  │
│                    │ architectural specifications, logs, or reports.   │
├────────────────────┼───────────────────────────────────────────────────┤
│ CURRENT            │ Reflects live operations and active field metrics │
│                    │ for the ongoing calendar year (2026).             │
├────────────────────┼───────────────────────────────────────────────────┤
│ HISTORICAL         │ Past project records, archived initiatives, or    │
│                    │ previous operational milestones.                  │
├────────────────────┼───────────────────────────────────────────────────┤
│ PROPOSED           │ Formally drafted in ratified architectural briefs │
│                    │ awaiting executive or trustee sign-off.           │
├────────────────────┼───────────────────────────────────────────────────┤
│ CONCEPT            │ Theoretical architecture or early-stage prototype │
│                    │ exploring feasibility. Clearly labeled as such.   │
├────────────────────┼───────────────────────────────────────────────────┤
│ UNVERIFIED         │ Uncorroborated records or external references.    │
│                    │ Strictly barred from public claims.               │
└────────────────────┴───────────────────────────────────────────────────┘
```

### Truth Enforcement Rules
1. **No Phantom Capabilities:** Never present a planned feature as "currently available" or a concept as a "live service".
2. **Regulatory Honesty:** Financial, remittance, pawn, and medical initiatives must explicitly declare their regulatory posture (e.g. `Research Sandbox`, `Technical Framework`, `Partner Pilot`).
3. **No False Scale:** Beneficiary counts and transaction volumes must link to verifiable database ledgers or documented pilot baselines.

## 2. Bilingual Governance (Bangla & English)

STFL operates on a strict **Dual-Authoritative Bilingual Standard**:
- **Bangla (বাংলা):** The primary cultural, legal, and community language of STFL's foundational territory.
- **English (EN):** The primary international, technical, and cross-border partner language.

### Localization Rules
- **No Runtime Machine Translation:** All core headings, navigation chips, and disclaimers are written by human translators.
- **Consistent Vocabulary:**
  - `Programs`: কর্মসূচি
  - `Initiatives & Ventures`: উদ্যোগ ও ভেঞ্চার
  - `Human Dignity`: মানব মর্যাদা
  - `Practical Action`: বাস্তব পদক্ষেপ
  - `Measurable Impact`: পরিমাপযোগ্য প্রভাব
  - `Controlled Project`: নিয়ন্ত্রিত প্রকল্প
  - `Agreement`: চুক্তি
  - `Receipt`: প্রাপ্তি রসিদ
  - `Verification`: সত্যতা যাচাই
