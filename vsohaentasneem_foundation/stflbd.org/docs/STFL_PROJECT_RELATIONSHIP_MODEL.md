## 1. Universal Relationship Taxonomy

To prevent legal ambiguity, corporate piercing of the corporate veil, and misrepresentation of charitable vs. commercial assets, every initiative connected to STFL is governed by an explicit relationship classification:

```
┌────────────────────────────────────────────────────────────────────────┐
│                   STFL RELATIONSHIP CLASSIFICATION                     │
├──────────────────────────┬─────────────────────────────────────────────┤
│ RELATIONSHIP CODE        │ LEGAL & OPERATIONAL DEFINITION              │
├──────────────────────────┼─────────────────────────────────────────────┤
│ STFL_PROGRAM             │ Direct internal charitable program of the   │
│                          │ foundation. Funded by core endowment/donations. │
├──────────────────────────┼─────────────────────────────────────────────┤
│ STFL_CONTROLLED_PROJECT  │ Project wholly owned, governed, and operated│
│                          │ by STFL Trust (e.g. GrihostiOS).            │
├──────────────────────────┼─────────────────────────────────────────────┤
│ STFL_INITIATIVE          │ Mission-aligned public initiative incubated │

│ UNVERIFIED               │ Preliminary concept or historical record    │
│                          │ prohibited from public representation.      │
└──────────────────────────┴─────────────────────────────────────────────┘
```

## 2. Institutional Separation of Varizen Inc.

### Constitutional Boundary Rule
**Varizen Inc. is strictly excluded from the STFL Initiatives & Ventures build.**

1. **Corporate Entity:** Varizen Inc. is an independent technology corporation registered in Wyoming, USA. It is not an STFL subsidiary, not an STFL endowment property, and not an STFL charitable venture.
2. **Branding Boundary:** STFL web properties shall never adopt Varizen corporate styling, shall not reproduce Varizen's commercial portfolio, and shall not represent Varizen products as foundation-owned initiatives.
3. **Public Presentation:** The Initiatives & Ventures directory (`/initiatives`) strictly catalogs foundation-governed and portfolio-aligned initiatives. Varizen Inc. receives zero public venture listings within this build.
4. **Attribution Integrity:** The respectful engineering attribution `(ঢাকা, কুয়ালালামপুর, ওয়াইওমিং এবং ভ্যারিজেন ইনকর্পোরেটেড থেকে ভালোবাসায় তৈরি)` in technical documentation acknowledges multi-regional development contributions without compromising institutional or legal independence.

## 4. Public Language Standards

When referencing initiatives on public web routes, documentation, or social releases, the following exact phrasing rules apply:

- For GrihostiOS: `"A project of SohaelTasneem Foundation"` or `"An institutional operating system of STFL"`
- For SkillConnect: `"An initiative of SohaelTasneem Foundation"`
- For AEV Developments: `"A development partner in the STFL ecosystem"`
- For MaxRemit: `"A financial access initiative supported by the STFL ecosystem"`
- For Helpex: `"A collateral finance project governed within the STFL ecosystem"`
- For Proiozon: `"A digital marketplace initiative developed within the STFL ecosystem"`
- For Perlu: `"A regional community marketplace partner in the STFL ecosystem"`
- For OIIX: `"A community media initiative supported by STFL"`

**Prohibited Phrasing:** Never refer to third-party or portfolio ventures as "STFL Branches", "STFL Subsidiaries", or "Charity Offices".
