## 1. Project as First-Class Governed Entity

In STFL AIO, a **PROJECT** is not a mere category tag; it is an autonomous, fully governed sub-organization operating under constitutional platform security.

### Core Capabilities per Project
- **Custom Web Identity:** Dedicated subdomain, visual identity, and public landing.
- **Dedicated Stakeholder Roster:** Project members can be onboarded without granted access to STFL foundation consoles.
- **Isolated Accounting:** Two-tier ledger (Project level chart of accounts rolled up to consolidated STFL portfolio).
- **Project-Specific AI Agents:** Scoped agents operating strictly within project datasets.
- **Zero Cross-Project Data Leakage:** Invariant 12 strictly enforced at PostgreSQL RLS and API middleware layers.
