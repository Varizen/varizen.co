--------------------------------------------------------------------------------
1. WHY THE FONTS WERE NOT DOWNLOADED
--------------------------------------------------------------------------------

Adrian Frutiger (1928-2015) designed typefaces that are all commercially
licensed. They are NOT open source and NOT in the public domain. Downloading
them from "free font" sites, GitHub mirrors, or CDN dumps would be copyright
infringement and a licence violation.

Every Frutiger typeface is owned and licensed by Monotype / Linotype (Monotype
acquired Linotype in 2006). A webfont licence must be purchased per domain and
per pageview tier. I did not download them, and I recommend you do not either.

5. HOW THE BILINGUAL SPLIT NOW WORKS
--------------------------------------------------------------------------------

Mukta has NO Bengali glyphs. That is intentional and is what makes the split
clean: the browser resolves each character against the stack in order.

  Latin / digits / punctuation  ->  Mukta          (Frutiger-style)
  Bengali codepoints U+0980-09FF ->  Hind Siliguri  (unchanged, brand-mandated)
  Fallback if both fail          ->  Noto Sans Bengali -> system-ui

Because every Mukta @font-face declares a unicode-range that excludes Bengali,
Bengali text can never be rendered by Mukta even if it is first in the stack.
Verified in-browser: Bengali sample "(ঢাকা, কুয়ালালামপুর, ওয়াইওমি" resolves to
Hind Siliguri at 17.6px; Latin resolves to Mukta.

8. SEPARATE BUG FOUND DURING VERIFICATION (NOT FIXED)
--------------------------------------------------------------------------------

globals.css contains this selector inside the STFL-TYPOGRAPHY-V2 block:

    [class*="lead"] { font-size: clamp(1.05rem, 1.25vw, 1.2rem); }

The substring "lead" also matches every Tailwind "leading-*" class
(leading-relaxed, leading-tight, leading-[1.08], ...). Because this rule is
unlayered it beats @layer utilities.

Measured impact on the live homepage:
  49 elements match the selector
  49 of those are leading-* only (zero are actual "lead" paragraphs)
  The hero <h1> renders at 18.48px instead of its intended 44-61.6px
  Every h2, h3 and body paragraph in those sections is also pinned to 18.48px

Suggested fix (one line):
    [class*="lead"]  ->  [class~="lead"]

This is a pre-existing defect, independent of the font work, and it changes
site-wide visual output, so it was left for your decision.

--------------------------------------------------------------------------------
9. RECOMMENDATION
--------------------------------------------------------------------------------

Short term   Ship Mukta. It is free, self-hosted, offline-safe, and visually
             in the Frutiger family. Zero licence risk.

Long term    If the brand genuinely requires Frutiger or Univers, buy a
             single-domain web licence from Monotype or use Adobe Fonts via a
             Creative Cloud subscription, then swap the family name in
             globals.css. The unicode-range split already in place means only
             the Latin @font-face blocks need to change.

Do not source these fonts from free-download sites. Beyond the legal exposure,
those files are frequently re-cut, mis-hinted or malware-wrapped, and they will
break Bengali conjunct rendering when mixed into this stack.
