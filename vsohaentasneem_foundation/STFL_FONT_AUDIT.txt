--------------------------------------------------------------------------------
6. PROBLEMS FOUND
--------------------------------------------------------------------------------

[1] JETBRAINS MONO IS NEVER LOADED
    794 elements request font-mono. No @font-face exists and no CDN link is
    present. Every label, ID, metric and eyebrow renders in Consolas.
    Files: globals.css:46 (token only), all admin pages, Navigation, Footer.

[2] BALOO DA 2 IS NEVER LOADED
    globals.css:2 has @import url('https://fonts.googleapis.com/css2?family=
    Baloo+Da+2...'). The built CSS contains ZERO @import statements and the
    live HTML contains ZERO fonts.googleapis.com references. The import is
    stripped during build. Bengali body text falls through to Noto Sans Bengali.

[3] INTER IS LOADED BUT UNUSED
    layout.tsx:7 declares Inter and emits 7 @font-face rules + the
    --font-inter variable, but --font-sans puts Hind Siliguri first and no
    element uses a font-inter class. English text renders in Hind Siliguri.

[4] font-hind / font-noto ARE UNDEFINED CLASSES
    221 usages across 34 files. No .font-hind or .font-noto rule exists in
    the built CSS. They silently do nothing.
    Worst offenders: grihostios (10), brandcenter (10), 20 public pages (8 each).

[5] HIND SILIGURI IS LOADED TWICE
    next/font WOFF2 subsets AND 4 local TTFs from /fonts/. Both are active.
    Wasted bytes on every first visit.

[6] GLOBAL TYPOGRAPHY OVERRIDES TAILWIND UTILITIES
    The h1-h4, p, nav, article p, eyebrow and meta rules in globals.css:241-360
    sit OUTSIDE any @layer. Tailwind's .text-* utilities live inside
    @layer utilities. Unlayered CSS always beats layered CSS, so:
      - ~370 heading text-* classes are dead
      - ~355 paragraph text-xs/sm/[10px] classes are dead
      - 313 paragraph leading-* classes are dead
    Example: <h1 className="text-4xl"> renders at the global h1 clamp size,
    not 39.6px.

[7] OFF-BRAND SERIF ON HAKIM SARKER PAGE
    25 font-serif usages (Georgia / Cambria / Times New Roman) on
    initiatives/hakimsarker/page.tsx, plus 1 on grihostios, error and not-found.
    Not part of the approved brand system.

[8] MIXED SCALING BREAKS THE TYPE SCALE
    rem sizes grow 10% with --viewer-scale, but the 404 px-based sizes
    (9px, 10px, 11px, 15px) stay fixed. The small-text tier does not scale
    with the accessibility setting.

[9] NO FONT PRELOAD
    Live HTML has zero <link rel="preload" as="font">. Fonts are discovered
    only after CSS parse, delaying first paint of Bengali text.

[10] NO OPENTYPE FEATURE SETTINGS
     STFL_BRAND_SYSTEM.md:131 mandates font-feature-settings: "kern" 1,
     "liga" 1. No such declaration exists anywhere in the source.

--------------------------------------------------------------------------------
7. SPEC vs IMPLEMENTATION
--------------------------------------------------------------------------------

SPEC (STFL_VI_TYPOGRAPHY_SYSTEM.md / STFL_BRAND_SYSTEM.md)
  BN headings   Hind Siliguri 600/700
  BN body       Noto Sans Bengali 400/500  (Baloo Da 2 secondary)
  BN UI         Noto Sans Bengali / Baloo Da 2
  EN headings   Inter 600/700/800
  EN body       Inter 400/500
  Mono          JetBrains Mono 400/500/700

IMPLEMENTATION
  BN headings   Hind Siliguri 600/700          MATCH
  BN body       Hind Siliguri (not Noto)       MISMATCH
  BN UI         Hind Siliguri                  MISMATCH
  EN headings   Hind Siliguri (not Inter)      MISMATCH
  EN body       Hind Siliguri (not Inter)      MISMATCH
  Mono          Consolas (not JetBrains Mono)  MISMATCH

Net result: 5 of 6 spec rows are not implemented. The site is effectively
single-font (Hind Siliguri) plus a Consolas fallback.

--------------------------------------------------------------------------------
8. RECOMMENDED FIXES (priority order)
--------------------------------------------------------------------------------

P1  Self-host JetBrains Mono (400/500/700 WOFF2) and add @font-face rules.
    Removes the 794-element Consolas fallback.

P2  Self-host Baloo Da 2 or delete the dead @import and update the spec.
    Currently the spec promises a font the site never loads.

P3  Move globals.css:241-360 into @layer base so Tailwind text-* utilities
    work again. This is the single highest-impact change: it restores ~1,000
    currently-dead utility classes.

P4  Decide the English font. Either:
      (a) put Inter before Hind Siliguri in --font-sans, or
      (b) drop Inter entirely and update the spec to "Hind Siliguri for all".
    Today Inter is downloaded and never used.

P5  Remove the duplicate Hind Siliguri load. Keep next/font WOFF2 subsets and
    delete the 4 local @font-face TTF blocks (or vice versa).

P6  Define .font-hind and .font-noto, or remove the 221 dead usages.

P7  Replace font-serif on hakimsarker with the approved stack.

P8  Convert the 404 px-based sizes to rem so the viewer scale applies uniformly.

P9  Add <link rel="preload" as="font" type="font/woff2" crossorigin> for the
    primary Bengali weight.

P10 Add font-feature-settings: "kern" 1, "liga" 1 to body per brand spec.
