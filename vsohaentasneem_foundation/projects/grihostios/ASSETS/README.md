- Raster: [randcenter/assets/raster/](../../brandcenter/assets/raster/)

Filter [randcenter/registry/assets.json](../../brandcenter/registry/assets.json) by project ID `STFL-PRJ-2026-0001` for the authoritative list.

## Production paths

This project's logo is served in production from `stflbd.org/public/media/`. That path is **unchanged** — the Brand Center holds a canonical copy, not a replacement.

See [portfolio/DEPENDENCY_MAP.md](../../portfolio/DEPENDENCY_MAP.md) for the exact reference list.

## Adding an asset

1. Copy into the Brand Center under the correct category
2. Register it in `brandcenter/registry/assets.json`
3. Record the production path if one exists
4. Never move a production-referenced asset
