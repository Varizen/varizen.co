# HAWLAT — API Specification (v1)

Base `/api/v1`, JSON, OpenAPI generated by FastAPI; contract snapshot tested in CI.

## Rules
- Auth: short-lived JWT + rotating refresh; step-up for sensitive actions. RBAC **plus** object-level ownership checks on every route.
- Mutations require `Idempotency-Key`; concurrency via `If-Match`/`version`.
- Errors: RFC 7807 `problem+json` with stable `code`; no internals leaked.
- Money: string decimals `"1500.00"` + `currency`.
- Cursor pagination, per-actor/IP rate limits, request IDs.
- Regulated routes call the Regulatory Gate first; blocked → `403 GATE_BLOCKED` with `feature`, `status`.

## Resources

| Area | Endpoints |
|---|---|
| Auth | `POST /auth/register`, `/auth/login`, `/auth/refresh`, `/auth/logout` |
| Identity | `POST /identity/verifications`, `GET /identity/status` |
| Participants | `GET/PATCH /participants/me`, `GET /participants/{id}/public-profile` |
| Reputation | `GET /reputation/me`, `GET /reputation/me/events`, `POST /reputation/appeals` |
| Requests | `POST/GET /requests`, `POST /requests/{id}/publish`, `/cancel` |
| Offers | `POST/GET /offers`, `POST /offers/{id}/publish`, `/withdraw` |
| Matching | `GET /requests/{id}/matches`, `GET /offers/{id}/matches` |
| Quotes | `POST /matches/{id}/quotes`, `GET /quotes/{id}` (breakdown + reason codes) |
| Agreements | `POST /quotes/{id}/accept`, `GET /agreements/{id}`, `POST /agreements/{id}/sign` |
| Transactions | `GET /transactions`, `GET /transactions/{id}`, `GET /transactions/{id}/timeline` |
| Repayments | `POST /transactions/{id}/repayments` (party-reported/confirmed record) |
| Passport | `GET /passport/me` |
| Disputes | `POST /disputes`, `POST /disputes/{id}/evidence`, `GET /disputes/{id}` |
| Notifications | `GET /notifications`, `POST /notifications/{id}/read` |
| Consent | `GET/POST /consents` |
| Admin (separate role + MFA) | `/admin/gates`, `/admin/config`, `/admin/risk-cases`, `/admin/compliance-cases`, `/admin/audit`, `/admin/kill-switches` |
| Health | `GET /healthz`, `/readyz` |

No endpoint provides "financing from HAWLAT" and none exports contact lists (no contact harvesting).
