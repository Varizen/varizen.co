## 1. Photography principles

| Principle | Detail |
|---|---|
| Dignity first | Subjects are portrayed with agency, never as passive recipients |
| Real, not staged | Documentary tone over stock-photo gloss |
| Context visible | Place, work and community are part of the frame |
| Consent recorded | Every identifiable person has recorded consent |
| No poverty porn | Distress is never the aesthetic |

## 4. Technical requirements

| Requirement | Value |
|---|---|
| Format | JPEG for photography, PNG for artwork with transparency, SVG for vector |
| Colour profile | sRGB |
| Minimum width | 1600 px for full-bleed |
| Compression | Optimised for web; no visible artefacts |
| Alt text | Required on every image |
| Decorative images | `alt=""` and `aria-hidden="true"` |

---

## 5. Consent and rights

| Requirement | Detail |
|---|---|
| Model release | Required for identifiable individuals |
| Guardian consent | Required for minors |
| Usage scope | Recorded per asset |
| Withdrawal | Honoured immediately; asset moves to `archive/` |
| Attribution | As recorded per asset |

Consent records are **not** stored in this repository. Where no record exists, the field reads `NOT RECORDED`.

---

## 6. Prohibited

| Prohibited | Reason |
|---|---|
| Unconsented identifiable subjects | Rights violation |
| Distress as aesthetic | Violates dignity principle |
| Stock photography presented as STFL work | Misrepresentation |
| AI-generated imagery presented as documentary | Misrepresentation |
| Recolouring photography to match brand palette | Distorts reality |
| Cropping a subject's face | Violates dignity principle |
