# Campaigns

Campaign-specific creative.

## Current contents

Empty. No campaign creative is present in this repository.

## Adding a campaign

1. Create `campaigns/<campaign-slug>/`
2. Place creative inside
3. Register each asset in [`../registry/assets.json`](../registry/assets.json)
4. Record the campaign's start and end dates
5. Move to [`../archive/`](../archive/) when the campaign ends
