# 22. FINANCIAL TECHNOLOGY RULES

For every financial product:

NEVER:

- Use floating-point arithmetic for money
- Trust client-side financial calculations
- Allow non-idempotent financial mutations
- Hide financial state transitions
- Modify transaction history without auditability

Use:

- Decimal / Numeric
- Idempotency keys
- Immutable audit records
- State machines
- Reconciliation
- Outbox pattern
- Provider abstraction
- Risk controls
- Release guards
